Registrar producto

Completa los datos para preparar un producto.

Máximo 120 caracteres. El nombre es obligatorio. El nombre no puede contener solo espacios. El nombre no puede superar 120 caracteres.
Debe estar entre 0 y 99,999,999.99, con hasta dos decimales. El precio es obligatorio. El precio no puede ser negativo. El precio no puede superar 99,999,999.99. El precio debe tener como máximo dos decimales.
El stock es obligatorio. El stock no puede ser negativo. El stock debe ser un número entero.
