## Estándar visual de la interfaz

Todos los componentes implementados deberán utilizar la misma guía visual para mantener consistencia entre catálogo, formularios y carrito.

### Paleta de colores

| Uso | Nombre | Hexadecimal |
|---|---|---|
| Color principal | Purple | `#6C3EB8` |
| Principal claro | Light Purple | `#A78BFA` |
| Color secundario | Dark Navy | `#2D2A4A` |
| Fondo principal | Soft Purple | `#F3EBFF` |
| Superficie / tarjetas | Light Gray | `#E5E7EB` |
| Texto principal | Dark | `#1F2937` |
| Texto secundario | Gray | `#6B7280` |
| Éxito | Green | `#10B981` |
| Error | Red | `#EF4444` |
| Advertencia | Amber | `#F59E0B` |

### Aplicación sugerida

#### `#6C3EB8`
Usar en:

- botones principales;
- acciones primarias;
- elementos seleccionados;
- encabezados destacados.

#### `#A78BFA`
Usar en:

- hover;
- selección secundaria;
- elementos decorativos;
- estados activos suaves.

#### `#2D2A4A`
Usar en:

- barras;
- encabezados secundarios;
- navegación.

#### `#F3EBFF`
Usar como:

- fondo general de la aplicación.

#### `#E5E7EB`
Usar en:

- paneles;
- tarjetas;
- fondos de tablas;
- divisores.

#### `#1F2937`
Usar para:

- títulos;
- texto principal;
- contenido de tablas.

#### `#6B7280`
Usar para:

- descripciones;
- placeholders;
- texto secundario.

#### `#10B981`
Usar exclusivamente para:

- operaciones exitosas;
- confirmaciones;
- estados correctos.

#### `#EF4444`
Usar para:

- errores;
- validaciones incorrectas;
- acciones destructivas.

#### `#F59E0B`
Usar para:

- advertencias;
- avisos;
- estados que requieren atención.
